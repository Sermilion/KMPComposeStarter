## [2026-08-28] KMP-1 subtask 2 — boundaries, DI lifecycle, ViewModel machinery, codegen hardening
Areas: core/domain, core/data, core/common, core/ui, composeApp (+ios/jvm/android hosts), androidApp, feature/{auth,home,profile,settings}, codegen/viewmodel-inject-processor, build-logic/convention, gradle, docs/architecture
- Dependency rule restored: `AuthRepository`, `LoginResult`, `TokenStore`, `DemoCredentials` and the sealed `AuthError` now live in core:domain; `StarterAuthRepository` binds from data via `@ContributesBinding`. No feature module depends on core:data, and core:data exposes no `api()`. `UserData` lost its token and `@Serializable`.
- One domain error type replaces the three parallel error shapes; ViewModels map typed reasons to UI strings and no user-facing English remains in data. `withRestErrorHandling` rethrows `CancellationException`.
- Session lifecycle (reusable pattern): `StarterUserComponentManager` is a single StateFlow source of truth whose transitions run under an atomicfu lock, so a sign-in can never overtake a concurrent sign-out and teardown is exactly-once. Teardown is a multibound `UserScopedCloseable` set plus a `@SingleIn(UserScope)` `CoroutineScope`; `logout()` tears down in a `finally` regardless of the network call's outcome.
- ScreenScope is real: `ScreenComponentHolder` lives in the nav entry's `ViewModelStore`, so `@SingleIn(ScreenScope)` shares within a screen and dies with the entry. `rememberNavEntryViewModelStoreOwner` (core:ui, reusable) survives configuration changes but drops all entry stores at session end — Navigation 3 keys stores by content key, so without it the next user would inherit the previous session's screen components.
- One ViewModel factory, one registration mechanism: `DIViewModelFactory` and the old `ViewModelFactory` are gone, `StarterViewModelFactory` is parameterized by scope with `associateBy` lookup and loud duplicate detection; hand-written `AppScopedViewModelModule` deleted — the processor now registers every ViewModel through the dedicated `@ContributesViewModel(scope)` annotation instead of overloading `@SingleIn`.
- Assisted-args key contract fixed on both sides: typed args are keyed by constructor parameter name, and `@Assisted savedStateHandle` is required rather than resolved by name-magic with a swallowed exception.
- Processor hardening: the DI package is a KSP option (`di.package`) wired through `KmpKotlinInjectConventionPlugin`; unknown scopes fail the build via `logger.error`; invalid symbols are deferred across rounds; `Dependencies(aggregating = false)` with a null-safe `containingFile`; `printStackTrace` dropped. New compile-testing suite covers happy path, assisted params, SavedStateHandle, unknown-scope failure, and deferral.
- Platform hosts deduped: shared commonMain `AppComponent` + one `StarterRoot(component)` composable replace three copy-pasted wiring blocks; iOS/JVM graphs moved out of `remember { }` into process-level holders matching Android's Application-owned lazy; the two byte-identical iOS factory actuals collapsed into `iosTargetMain`. App scope gained a Kermit-logging `CoroutineExceptionHandler` behind an `UnhandledErrorReporter` seam.
- Known limitation: `TokenStore` is an in-memory binding and demo credentials are still injected constants — subtask 3 backs both with DataStore/real networking. Assisted-args and SavedStateHandle have codegen coverage but no consuming exemplar until subtask 5's `DetailRoute`.
